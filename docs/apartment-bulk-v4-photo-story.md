# 아파트 블로그 V4: 실제 사진 + 실거래 중심 편집

## 핵심 원칙
- **기존 아파트 단지 분석 V3/3.1**, 실거래 원본 연결, 실거래 자동 검사, 학군/초대형단지/분양 도구와 저장된 글을 변경·삭제하지 않고 별도 V4 편집 작업판을 더했습니다.
- 단지별 제작 편집판에서 V3/V4를 선택하며, V4는 썸네일 포함 6/7/8장 구성입니다.
- V4 원고는 사진·데이터 이미지 한 장마다 짧은 설명 2~3줄. 가격·면적·시점·실거래 출처는 확인된 내용만 사용합니다.
- 사진은 직접 촬영하거나 별도 사용 허가가 있는 실사진을 우선합니다. 네이버 사진 검색 결과는 **단지 확인 참고용**이지 재사용 허가가 아닙니다.
- Pexels 같은 스톡 사진은 실제 특정 단지 사진으로 소개하면 안 됩니다.
- 02 그래프는 사이트의 같은 전용면적·해당 단지 **연동된 월별 실거래 대표값**이 최소 2개 있어야 직접 만들 수 있습니다. 원본이 연결되지 않았다면 그래프 버튼은 비활성화합니다.
- 개별 거래일/층수, 인근 단지 정확한 실거래가, 도보 거리/학군은 추가 공식 확인 전 임의로 만들지 않습니다.
- 본문 이미지는 `[이미지 01]` 등으로 배치합니다. 완성된 글과 사진은 같은 화면에서 순서대로 미리 볼 수 있습니다.
- 사용 사진은 별도 IndexedDB `apartment-bulk-v4-studio-images`에 단지·작업 식별자별로 저장합니다. 기존 이미지와 충돌하지 않습니다.
- ZIP에는 원고, 등록한 모든 PNG, 각 장면의 이미지 제작 요청서, 사진 출처, 검사 결과가 들어갑니다.

## 사용 순서
1. 아파트 단지 선택 후 실거래 원본이 맞게 연결됐는지 확인합니다.
2. V4 제작 방식과 이미지 수(6·7·8장)를 선택합니다.
3. `ChatGPT에서 V4 원고 작성`을 눌러 검증 기준을 담은 글과 이미지 기획 메모를 만듭니다.
4. 원고를 V4 입력창에 붙여넣으면 기존 네이버 최종 편집 입력창에도 함께 반영됩니다.
5. 실제 단지 참고 사진을 검색하고, 사용할 권리가 있는 실사진을 등록합니다. 외부사진은 사진가/기관, 원본 URL, 허락 확인을 반드시 입력합니다.
6. 02번 데이터 그래프는 원본 월별 가격이 2개월 이상 있을 때 사이트에서 직접 제작할 수 있습니다. 나머지 이미지에는 슬롯별 ChatGPT 요청서를 활용합니다.
7. V4 사진·글 미리보기를 확인하고 기존 발행 전 자동 검사도 완료한 뒤 ZIP을 만듭니다.
8. 네이버 서식복사는 글만 복사합니다. 등록 사진은 네이버 편집기에도 별도로 올려야 합니다.

## 개인정보와 저작권
- AI 제작 예시 이미지를 특정 아파트의 실제 모습처럼 표기하지 않습니다.
- 허가 없는 보도자료·카페·부동산 플랫폼 사진을 무단 복제하지 않습니다.
- 사진가·제공기관·출처와 허가 범위는 발행 전에 사용자에게 확인이 필요합니다.
- 완성 원고를 붙여넣어도 앱이 모든 사진의 동일성·권리를 자동 보증하지 않습니다.

## 범위
이번 PR은 아파트 **단지 실거래 분석** 경로에 V4를 추가합니다. 분양, TOP3, 학군은 기존 제작 과정을 유지하며 향후 별도의 데이터 구조에 맞춰 확장할 수 있습니다.
