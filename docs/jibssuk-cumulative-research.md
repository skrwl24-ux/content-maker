# 집값쓱 조사 누적

`feat/jibssuk-cumulative-research`에서 `/jibssuk-queue`의 조사 가져오기만 누적 방식으로 변경한다. Paramma 및 다른 작업실의 파서·프롬프트는 유지한다.

- 최초 보고서와 매회 추가 보고서 원문을 보관한다. 기존 `acceptedRaw` 작업은 동일한 localStorage 키에서 최초 보고서로 읽으며 기존 원고·관점·이미지 메모를 보존한다.
- 추가 입력은 `RESEARCH_ADDENDUM_JSON`, 기존 `RESEARCH_REPORT_JSON`, JSON 또는 코드블록을 지원한다. 한 보고서의 중복 ID나 잘못된 참조는 원본을 변경하지 않고 오류로 반환한다.
- 동일 주장과 사건 맥락만 중복 제거한다. 유사한 문장을 자동 병합하지 않는다. 같은 출처의 발표일이 다르면 별도 사실로 보존한다. 새 출처는 기존 사실에 연결하고 새 사실/관점 ID 충돌은 재배정한다.
- 구조화된 대상·항목·사건일·비교 범위의 값이 다르면 확인 필요로 남긴다. 기존 형식에서는 같은 문장 틀의 숫자 차이만 보수적으로 탐지한다. 의미가 다른 문장의 충돌을 모두 자동 탐지하는 기능은 아니다. 원문과 통합 보고서로 추가 확인한다.
- 미해결 질문은 삭제하지 않는다. 해결 보고는 별도 이력으로 보관하며 자동 검증하지 않는다. 발견 후보와 전체 출처·기준일은 최종 원고 요청서에 전달한다. AI의 실제 조사·원고 품질은 별도 확인이 필요하다.
- 회차 복원은 보기를 되돌리며 후속 원본을 삭제하지 않는다. 과거 상태에서는 새 회차를 받지 않고 최신 상태로 돌아오도록 안내한다. 원고는 자동 변경하지 않는다.
- 새 보고서와 전체 저장 데이터는 1,500,000자 상한이며 초과·브라우저 quota 오류 시 기존 저장 데이터를 덮어쓰지 않는다. 조용한 배열/문장 잘림은 하지 않는다. 작업·이력 JSON 다운로드로 백업할 수 있다. 손상되거나 지원하지 않는 저장 형식은 자동 저장을 막아 보호한다. 다운로드 파일을 다시 업로드하는 별도 UI는 이번 범위에 추가하지 않았다.

검증 명령: `node tests/jibssuk-research-history.cjs`, `npm run build` (신규 테스트 포함). 실제 브라우저에서는 기존 v1 작업 복원, 추가 조사 병합, 기존 원고·관점 유지, 새로고침, 과거/최신 회차 복원, 글감별 저장 분리를 확인한다.

현재 main SHA는 시작 시 `bdc41bff0c3f2ae14fd693e77f17b2b6082db906`과 일치했다. 운영 URL 접근은 환경 네트워크 정책에서 403으로 차단되었다. Vercel 인증/연결 정보가 없어 프리뷰·운영 배포는 수행하지 않았다. 원격 main 반영도 하지 않았다.

최종 검증: `npm run build`에서 테스트 파일 36개 통과, 실패 0개, Next.js 컴파일·타입 검사·정적 페이지 생성 완료. 신규 병합 테스트 5개 시나리오 직접 실행 통과. Chromium에서 위 데이터 보존 흐름과 저장 공간 부족, 손상된 v1 데이터 보호까지 통과했으며 페이지 런타임 오류 없음. 네이버 편집기에 실제 붙여넣기, 실제 사진/지도 원격 요청, 외부 AI가 생성한 최종 원고의 품질은 이번에 직접 검증하지 않았다. 기존 네이버 서식·표·이미지·지도·사진 모듈 회귀 검사는 통과했다.

변경 파일:
- `app/jibssuk-queue/JibssukArticleWorkflow.tsx`: 누적 가져오기, 이력·복원·다운로드, 원고 유지, 안전한 기존 작업 복원.
- `lib/jibssuk-research-history.mjs`, `.d.mts`: 집값쓱 전용 파서·병합·회차 관리·추가 조사 요청서.
- `lib/jibssuk-simple-workflow.mjs`: 최종 원고에 누적 자료와 내부 편집 판단 전달.
- `lib/research-studio.d.mts`: 추가 출처·관점 설명의 선택적 타입 필드. 공통 실행 로직 변경 없음.
- `tests/jibssuk-research-history.cjs`: 신규 데이터 보존·누적·충돌·출처·프롬프트 테스트.
- `tests/jibssuk-research-handoff.cjs`: 변경된 전용 함수 연결 검사.
- `package.json`: 기존 빌드 검증에 신규 테스트 추가. 의존성 변경 없음.
- 이 문서: 동작, 검증 결과와 배포 제한 기록.
