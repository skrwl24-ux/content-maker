# 콘텐츠 메이커 공통 편집장 V1 · 검토 브랜치

## 목적
블로그 글을 많이 생성하기보다 **독자가 어떤 답을 원하는지**와 **AI 일반 답변보다 무엇이 유용한지**를 먼저 판단한다. 글이 짧아도 질문을 해결하면 충분하다.

## 현재 연결
- 집값쓱 단지 원고 요청서: 공통 편집 철학 + 단지 검증 원칙
- 집값쓱 7칸 작업의 일반 원고·분양 요청서: 공통 편집 철학 + 기존 ‘자료·근거 메모’ 원문
- 집값쓱 검색 계획 요청서와 최종 요청서: 공통 편집 철학, 앞선 검색 계획의 출처 링크·기준일 전달
- Paramma 현재 작업의 본문 요청서 복사: 공통 편집 철학 + 별도 검색 메모 전달. 기존 저장된 원고는 그대로 유지
- 공통 파일: `lib/editorial-director.mjs` (정책 버전 1.0)

## 운영 방법
1. **발견한 소재**를 주제 칸에 입력한다. 예: 공개된 드라마 촬영지 관련 발표, 지역 단지 가격 비교, 새 동물 연구
2. **자료·근거 메모**에 공식 원문 URL, 기사/방송 제목, 발표일과 실제 사건일, 확인된 숫자, 불확실한 부분을 붙여넣는다. 링크만 있다고 사실 검증이 완료된 것은 아니다.
3. 집값쓱에서 **검색 가설·검증 요청**을 복사해 ChatGPT에 전달하고, 결과 `SEARCH_PLAN_JSON`을 다시 가져온다. 이 과정은 사이트 내부 웹 검색 기능이 아니다.
4. **GPT 요청서/본문 요청서 복사**로 자료와 편집 원칙을 같이 전달한다. Paramma에서는 본문·이미지 기획 요청서 복사를 사용한다.
5. 생성된 본문을 사이트에 넣고 기존 출처·데이터 검사와 사람의 원문 확인을 거쳐 발행한다.

## 최신 화제와 대중문화 연결
- 유행하는 배우·예능·드라마·영화·방송 장면은 **직접적인 연결 사실**이 확인될 때만 소재에 반영한다.
- ‘TV 화면에 나온 공간’, ‘실제 촬영 장소’, ‘배우의 공개 발언’을 혼용하지 않는다. 비공개 주거지를 찾거나 노출하지 않는다.
- 최신성은 **발견 시각 / 발표 시각 / 실제 사건 발생 시각 / 원문 확인 시각**이 다를 수 있음을 표시한다.
- 자동 트렌드 검색, 출처 크롤링, 실시간 연예인 관련성 판단은 **미구현**. 글쓰기 요청서로 조사하기 위한 조건만 마련했다.

## 중요 한계
- 공통 편집 정책은 AI가 사실 확인을 실제로 수행했음을 보장하지 않는다.
- `SEARCH_PLAN_JSON`의 링크와 날짜는 이전 조사 출력이며 최종 집필 시 재검증 대상이다.
- Paramma V4의 지정 이미지 슬롯과 별도 글쓰기 템플릿은 아직 기존 방식이 유지된다.
- 장문 원본은 최종 원고 요청서에서 잘라내지 않지만, 검색 계획 연구 요청서는 과도한 자료 길이를 제한하고 **명시적 경고**를 추가한다. 원본 파일이나 캡처는 별도 업로드해야 한다.
- GitHub 검토 브랜치/PR에만 적용. 사용자 확인 전 운영 `main` 병합·프로덕션 배포 금지.
