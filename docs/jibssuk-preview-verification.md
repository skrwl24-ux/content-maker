프리뷰 **실제 화면 검사는 미완료**다. Vercel 로그인 보호로 리디렉션된다. Vercel CLI 65.8.0 `whoami`는 로그아웃, 비대화형 `vercel curl`은 `No existing credentials found`, 기존 프로젝트/팀을 지정한 `@vercel/oidc` 조회도 사용 불가였다. 인증이 없자 CLI가 시작한 대화형 로그인은 중단했다. 새 로그인 인증 완료·장기 키 발급·보호 해제·새 프로젝트 생성은 하지 않았다. GitHub 인증은 사용 가능하며 기존 Vercel 봇의 배포 상태는 확인할 수 있다.

지도/사진은 로컬 브라우저 검사에서 초기 검색 실패 응답을 명시적으로 대체해 메모 보존을 검사했다. 실제 NAVER/Supabase 원격 서비스, 실제 네이버 편집기 붙여넣기, 외부 AI의 조사 사실·원고 품질은 검증 완료로 보지 않는다.

## 브라우저 검사 재현

별도 설치된 Playwright와 Chromium을 사용한다. 앱 의존성에 브라우저 도구를 추가하지 않는다.

```bash
# 별도 터미널에서, 빌드 후
npm run start -- --hostname 127.0.0.1 --port 3003

# Playwright가 표준 모듈 경로에 없으면 PLAYWRIGHT_MODULE에 설치 경로 지정
PREVIEW_BASE_URL=http://127.0.0.1:3003 \
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright \
node scripts/verify-jibssuk-preview.cjs
```

스크립트는 새 브라우저 컨텍스트에 합성 localStorage만 입력하고 클라우드 DB에 쓰지 않는다. 지도·사진 초기 응답은 테스트 대체 응답이므로 실서비스 성공을 뜻하지 않는다. 원격 프리뷰에서 실행하려면 프리뷰에 대한 승인된 접근이 먼저 필요하며, 스크립트는 인증 보호를 우회하지 않는다.

## 로그인 후 직접 확인

기존 작업 데이터를 보호하려면 프리뷰 전용 브라우저 프로필에서 새 글감을 사용한다. 운영 사이트의 저장 데이터를 지우지 않는다.

1. 위 프리뷰 링크에서 기존 Vercel 계정으로 로그인한다. PR의 Vercel 검사와 브랜치 최신 커밋이 일치하는지 확인한다.
2. 10칸 발행 목록에서 새 글감을 선택하고 최초 조사 JSON을 가져온다. 관점을 선택한 후 제목·본문·이미지 출처 메모를 입력한다.
3. 2번의 추가 조사 가져오기로 기존 사실 2개와 신규 사실이 든 결과를 넣는다. 신규·중복 집계가 실제 자료와 맞고 기존 사실/원고/관점/메모가 남는지 확인한다. 추가 조사를 3회 반복한다.
4. 관점을 바꾼 뒤 새로고침한다. 같은 글감에서 조사·관점·원고·메모가 복원되고 다른 글감의 데이터와 섞이지 않는지 확인한다.
5. 비교표가 있는 원고를 네이버 서식으로 복사해 실제 네이버 편집기에 붙여넣고 값·문단·표를 확인한다. 표 PNG와 이미지 00~03 요청서, 원본 사진의 1600×900 PNG 저장을 확인한다.
6. 정확한 단지명으로 지도와 사진을 검색한다. 실제 마커·주소·단지 일치, 공식 조감도 여부·저작권은 직접 확인한다. 새로고침 후 저장한 출처 메모가 남는지 확인한다.

검증 결과 승인 전 main 병합·운영 배포를 하지 않는다.
