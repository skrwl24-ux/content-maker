# Paramma 수익형 주제 자동 조사 설정

## 목적
이 기능은 `/paramma-bulk`에서 **✨ 최신 수익형 후보 자동 조사·등록**을 클릭하면 최신 웹 검색을 포함한 AI 조사를 진행한 뒤 결과를 수익형 주제 후보 목록에 등록합니다.
수익형 주제는 직접 발행되지 않습니다. 사용자가 유효 기간·출처를 검토하고 큐 자리를 선택하거나 발행 완료 슬롯을 **갈아끼우기** 할 때 추천 후보로 사용합니다.

## 환경 변수 (Vercel → Project → Settings → Environment Variables)
- `OPENAI_API_KEY`: 서버에서만 사용되는 OpenAI API 키. 클라이언트에 노출하지 않습니다.
- `PARAMMA_RESEARCH_ACCESS_CODE`: 임의의 **12자 이상** 관리자 코드. GitHub, URL, 화면 예시 등에 실제 비밀번호를 기록하지 마세요.
- `PARAMMA_RESEARCH_MODEL` (선택): 기본 모델은 `gpt-5-mini`입니다. 별도 설정이 필요한 경우 API 지원 모델을 지정하세요.

브라우저에서 관리자 코드를 입력한 뒤 버튼을 눌러 조사를 실행할 수 있습니다. 코드는 React 메모리 상태에만 보관하고 브라우저 로컬 저장소, ZIP, 발행 이력 등에 저장하지 않습니다. HTTPS 연결에서만 사용하세요.

## 서버 동작
- `POST /api/paramma/research-money`는 동일 출처에서만 호출됩니다. 관리자 코드 불일치 시 401을 반환합니다.
- 서버가 OpenAI Responses API에 `web_search`를 사용한 최신 조사 요청을 보냅니다.
- 수집한 JSON 후보를 정규화하고 큐/발행 이력 중복, 기한 경과, 출처 URL 누락을 필터링합니다.
- 15분당 최대 3번의 **서버 인스턴스 내** 기본 요청 제한이 있습니다. 서버리스 인스턴스 간 공통 제한은 아닙니다. 다중 사용자에게 공개하거나 호출량이 많아진다면 별도의 영속적 속도 제한과 인증을 추가하세요.
- 사용자에게 키나 내부 API 응답 원문을 노출하지 않습니다. 검색 결과는 항상 발행 전에 검토해야 합니다.

## 사용 순서
1. 수익형 후보 영역에서 관리자 코드를 입력합니다.
2. 자동 조사 버튼을 클릭하면 최신 후보를 수집합니다.
3. 후보 목록에서 출처와 날짜를 확인합니다.
4. 특정 큐에 즉시 넣으려면 카드별 큐 자리를 선택하고 **넣기**를 누릅니다.
5. 발행 완료 슬롯의 **갈아끼우기**는 현재 수익형 3개 미만일 때 조건에 맞는 등록 후보를 우선 사용합니다.
6. API 설정이 아직 없다면 기존 **ChatGPT에서 수동 조사** 및 MONEY_JSON 붙여넣기 기능을 그대로 이용할 수 있습니다.

## 비용·운영 주의
OpenAI API는 ChatGPT 구독과 별도 요금이 청구됩니다. 프로젝트 계정에서 사용량 한도와 예산을 설정하세요. 페이지 방문 시 자동 호출하지 않으며, 관리자가 버튼을 누르는 경우에만 유료 호출을 시작합니다.
신청 자격·날짜·가격은 변할 수 있습니다. 소스 URL의 진위와 최신 정보는 발행 전 다시 확인해야 합니다.
