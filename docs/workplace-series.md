# 직장 주변 아파트 시리즈: 자료는 사이트, 작업은 챗

기존 콘텐츠메이커의 요청서·ZIP → ChatGPT → 결과 붙여넣기 방식을 따릅니다.
사이트 내부에서 AI 판독·글 생성을 호출하지 않으며 서버 AI 키가 필요하지 않습니다.

1. `/apartment-workplace`에서 단지를 추가하고 근무지를 지정합니다.
2. 근무지·출입구 → 단지정보 → 매매 → 전세 → 월세 → 현재 매물 → 도보 경로 순서로 자료를 첨부합니다.
   단계마다 확인 사이트 링크·캡처할 필수 항목을 안내합니다.
   PNG/JPEG/WebP, MP4/WebM/MOV, 파일당 50MB·영상 60초 이내입니다.
3. 출처 링크·메모·미확보 사유를 기록하고 다음 자료로 이동합니다.
4. ‘챗으로 전달’에서 전체 자료 ZIP을 받습니다. 단계별 자료만 먼저 챗으로 가져갈 수도 있습니다.
5. ChatGPT를 열고 ZIP을 **직접 첨부**한 뒤 요청서를 전송합니다.
   버튼은 새 챗을 엽니다. 현재 대화에 이어가려면 현재 채팅에 ZIP과 요청서를 직접 첨부하세요.
6. 챗에서 받은 원고를 사이트에 붙여넣어 단지별로 보관합니다.

## 패키지

- `00_request.txt`: 챗에서 판독·검증 범위를 구분하고 짧은 글을 작성하도록 하는 요청서
- `01_index.json`: 단지·확인일·단계별 첨부 목록·출처·메모·미확보 항목·기존 참고 입력
- `sources/`: 원본 이미지와 영상
- `frames/`: 긴 이미지의 겹치는 분할 화면, 영상의 최대 12개 시점 JPEG
- `README.txt`: 챗 첨부 방법과 자료의 한계

영상 화면 추출은 전체 영상을 대신하지 않으며 빠르게 지나간 정보는 누락될 수 있습니다.
긴 캡처는 최대 12개 구간입니다. 미첨부 항목은 확인 필요로 기록합니다.
원문 링크가 없으면 캡처·영상 기준임을 명시하고, 첨부 사실을 검증 완료로 표시하지 않습니다.
파일명은 경로 문자를 정리하며 순번으로 충돌을 방지합니다.
ZIP 생성은 브라우저에서 처리하고 원본·추출 화면을 서버로 업로드하지 않습니다.

## 보관 및 호환

첨부는 IndexedDB, 입력·메모·현재 단계·원고는 localStorage에 저장합니다.
다른 기기와 자동 동기화되지 않습니다. 기존 파일·입력·원고를 유지하며,
단계 미분류 첨부는 분류 메뉴로 배정할 수 있고 전체 ZIP에는 그대로 포함됩니다.
기존 내부 AI에서 반영한 기록은 참고 입력으로만 보존하고 원자료 대조를 요청합니다.

## 검증

- `node --test tests/workplace-handoff.cjs`: 단계별/전체 전달 범위, 파일 경로·출처·미확보 사유 보존
- `npm run build`: 기존 테스트·프로덕션 빌드
- 브라우저: 단계별 첨부와 복원, ZIP 원본·화면·요청서 확인, ChatGPT 링크,
  챗 결과 붙여넣기와 원고 보존, 모바일 레이아웃
