# Paramma V4 · 사진 중심 스토리텔링

## 작동 방식
- 기존 `/paramma-bulk`의 발행 큐 10개, 킥 선정, 네이버 서식 복사, PNG 업로드, ZIP을 유지합니다.
- 신규 글은 V4가 기본이고, 기존에 저장되어 있던 V3 글은 자동 변환하지 않습니다.
- 제작 방식에서 V3 ↔ V4를 선택하고, V4에서는 대표 썸네일 포함 **6장/7장/8장** 중 원하는 장수를 선택합니다.
- 장면은 00 썸네일, 01 첫 장면, 02 핵심 원리, 03 실제 사례, 04 상황 비교, 05 핵심 발견·보상, 06 추가 정보, 07 오해 해소·마무리입니다.
- ChatGPT에 넘기는 본문 요청서는 웹 사실 확인, 구체적인 이미지 기획 및 [이미지 NN] 위치표시, 이미지 사이의 짧은 설명을 안내합니다.
- 원고를 붙여넣으면 기획 메모 00~07과 본문의 이미지 위치를 확인합니다. 전체 이미지와 본문·검수 표시가 완료돼야 ZIP을 생성합니다.

## 사진 검색: Pexels
1. Vercel → 해당 프로젝트 → Settings → Environment Variables에 `PEXELS_API_KEY`를 추가합니다.
2. Pexels 개발자 API 페이지에서 키를 발급받습니다. 브라우저에서 입력하거나 GitHub 파일에 기록하지 않습니다.
3. Vercel에 설정을 적용한 후에는 새 프리뷰/운영 배포에서 `실제 사진 찾기 (Pexels)`를 눌러 검색합니다.
4. 사진을 선택하면 서버가 공식 Pexels 사진 ID로 사진을 확인한 뒤 PNG로 변환, 브라우저 이미지 저장소에 등록합니다.
5. 선택된 사진의 출처·사진가·사진 URL이 이미지 미리보기 및 ZIP의 `image_sources.txt`에 남습니다.

사진을 선택하는 기능이지, AI가 자동으로 사진의 출처/인물/과학적 진위를 보증하는 기능은 아닙니다.
Pexels API의 검색과 사진 상세 조회만 사용하고 임의의 이미지 URL은 서버로 전달하지 않습니다.
지원 가능한 외부 사진은 12MB 이하 JPEG/PNG/WebP입니다. 원본 가로세로 비율을 임의로 자르거나 늘리지 않습니다.

## 사진 이용·라이선스
Pexels 사진은 개인 및 상업용 블로그에 활용할 수 있지만, 사진 속 인물·브랜드·사유재산 관련 권리가 별도로 문제될 수 있습니다.
Pexels API에서 얻은 사진과 사진가 링크를 함께 표기하도록 했으며, 발행 문서에도 이미지 출처 표기를 권장합니다.
실제 사고·습격 등 사건 관련 글에 일반 스톡 사진을 증거 사진인 것처럼 사용하면 안 됩니다.
공식 가이드: https://www.pexels.com/api/documentation/ 및 https://www.pexels.com/license/

## 저장과 안전
- 본문·작업 상태의 기존 `localStorage` 키는 유지합니다.
- 이미지는 기존 `IndexedDB` 키를 유지하며, V3 00~03의 기존 이미지 기록은 자동 삭제하거나 이동하지 않습니다.
- 새로운 슬롯은 04~07에서만 추가 사용됩니다.
- 원고를 V3에서 V4로 바꿀 때 기존 작성 글·등록 이미지를 덮어쓰지 않으며, 위치 마커를 사용자가 맞춰야 합니다.
- 자동 사진 검색은 `PEXELS_API_KEY`가 없으면 오류 안내만 표시하고, ChatGPT/직접 업로드 방식은 계속 사용할 수 있습니다.
- 네이버 미리보기에서 이미지는 표시하지만 **네이버 서식 복사는 텍스트만** 복사합니다. 네이버 편집기에는 이미지를 별도 등록해야 합니다.
