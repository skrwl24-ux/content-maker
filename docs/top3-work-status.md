## 제한 / 다음 작업
- 수치의 의미적 일치는 사용자가 직접 검수한다. 시스템은 자동 사실 검증이나 지역 전체 순위 계산을 하지 않는다.
- ChatGPT의 실제 입력창 자동 채움은 이번 검증에 포함하지 않음. 기존 q 링크 방식 사용, 복사 기능 유지.
- 기기 간 동기화 아님. 같은 브라우저·origin의 IndexedDB 저장이며 저장 완료 확인 후 닫아야 함.
- 실제 서비스 배포와 프로덕션 데이터 검증은 별도. 이번 브라우저 검증은 localhost 테스트 데이터만 사용.
- 오늘판 기존 완료 체크 의미는 이번 범위에서 변경하지 않음. ZIP 다운로드가 완료 체크를 자동 변경하지 않음.
- 브라우저 다운로드 이벤트 대기는 시간 초과했으나 실제 Downloads ZIP 파일 생성·내용 검사는 완료됨.
