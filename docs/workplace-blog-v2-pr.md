- 00 썸네일 1254×1254, 01~07 본문 1600×900. 슬롯별 복사/ChatGPT 링크와 요청서 펼쳐보기를 제공하며 사진 검색·직접 촬영 추천을 AI 설명 카드와 구분합니다. 이미지 미리보기는 추가하지 않았습니다.
